# Contributing

This repository is a static bilingual educational frontend. Keep all contributor guidance aligned with code and docs already in this repo.

1. **Scope and accuracy boundaries:** Keep new explanations consistent with `/home/runner/work/little-ai/little-ai/README.md` ("Accuracy boundaries") and current teaching code in `/home/runner/work/little-ai/little-ai/src`; do not document live model/backend/web-search/image-generation calls that are not implemented.
2. **Node/npm setup:** Match CI and Pages workflow by using Node 24 (`actions/setup-node` in `/home/runner/work/little-ai/little-ai/.github/workflows/pages.yml`) and install dependencies with `npm ci`.
3. **Local commands:** Use the repo scripts documented in `/home/runner/work/little-ai/little-ai/package.json` and README: `npm run dev -- --port 4173`, `npm test`, `npm run build`, and `npm run preview`.
4. **Source map:** The app bootstraps in `/home/runner/work/little-ai/little-ai/src/main.tsx`, routes in `/home/runner/work/little-ai/little-ai/src/App.tsx`, page shells in `/home/runner/work/little-ai/little-ai/src/Pages.tsx`, lesson flow in `/home/runner/work/little-ai/little-ai/src/Lesson.tsx`, and chapter visuals in `/home/runner/work/little-ai/little-ai/src/demos/*`.
5. **Localized content helpers:** Keep chapter copy bilingual through `/home/runner/work/little-ai/little-ai/src/content.ts` helpers (`Lang`, `Localized`, `l(en, cs)`, and `text(value, lang)`) instead of hardcoding one language.
6. **Lesson metadata:** Respect the `Lesson` structure in `/home/runner/work/little-ai/little-ai/src/content.ts` (`id`, `group`, `name`, `subtitle`, `title`, `intro`, `scenes`, `takeaway`, `details`, `sources`) so chapter navigation and details rendering stay intact.
7. **Demo registration:** Add or rename chapter demos by updating the `demos` mapping in `/home/runner/work/little-ai/little-ai/src/demos/index.tsx`; `Lesson` resolves scenes by lesson `id` and returns `null` for unknown IDs.
8. **Captions and technical details:** Keep scene narration in `lesson.scenes[*].body` and deeper explanation in `lesson.details`/`lesson.sources`, because `/home/runner/work/little-ai/little-ai/src/Lesson.tsx` renders captions (`.scene-caption`) separately from the “Details & sources” panel.
9. **Original source attribution:** Add educational references to `/home/runner/work/little-ai/little-ai/src/content.ts` `sources` entries, and keep project-level inspirations/credits consistent with `/home/runner/work/little-ai/little-ai/README.md` and `/home/runner/work/little-ai/little-ai/src/Pages.tsx` (including Little Clip Factory acknowledgments).
10. **Hand-designed embeddings:** Treat vectors in `/home/runner/work/little-ai/little-ai/src/math.ts` (`documents`, `queryVectors`) and `/home/runner/work/little-ai/little-ai/src/demos/Beyond.tsx` notes as curated teaching data, not outputs from an embedding API.
11. **Training versus inference:** Keep the distinction explicit: `/home/runner/work/little-ai/little-ai/src/math.ts` demonstrates training with `train(...)` and prediction with `predict(...)`, while `/home/runner/work/little-ai/little-ai/src/content.ts` glossary defines inference as running a trained model.
12. **Tokenization encodings:** Keep tokenizer documentation aligned with supported encodings in `/home/runner/work/little-ai/little-ai/src/tokenizer.ts` (`cl100k_base`, `o200k_base`) and the same two options in `/home/runner/work/little-ai/little-ai/src/demos/Foundations.tsx`.
13. **Plain-text token count limits:** Document token counts as plain-text teaching counts only: `/home/runner/work/little-ai/little-ai/src/tokenizer.ts` rejects `input.length > 3000`, and `/home/runner/work/little-ai/little-ai/src/demos/Inside.tsx` states API formatting is excluded.
14. **Tokenizer worker boundary:** Keep heavy tokenization on the browser worker boundary (`/home/runner/work/little-ai/little-ai/src/useTokens.ts` creates `new Worker(new URL("./tokenizer.worker.ts", import.meta.url))`; `/home/runner/work/little-ai/little-ai/src/tokenizer.worker.ts` executes `tokenize`).
15. **Stale tokenizer replies:** Preserve request-order safety by keeping monotonically increasing request IDs and current-request checks in `/home/runner/work/little-ai/little-ai/src/useTokens.ts` (`event.data.request === counter.current`), with latest-only draining in `/home/runner/work/little-ai/little-ai/src/tokenizer.worker.ts`.
